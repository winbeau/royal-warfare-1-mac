# 第二章两场主场关实施规格（M1-S）

用户 2026-11-06 定的目标：先做两场主场关。

- **火铳主场 = 第 11 关「Siege at Stone Wharf」**：战场上有 6–10 名火铳卫，面对大批尸潮。
- **陌刀主场 = 第 23 关「Ride to West Cape」**：陌刀镇戍卫顶住达思重骑一波接一波的冲锋。

本阶段**只做**镇戍卫（刀盾、陌刀）和火铳卫（制式火铳、五雷神机、重管火铳）两个职业、5 把武器、10 个技能、敌人达思重骑。斩马刀、游骑、术师、随军僧，以及 N01–N05 等新敌人都不在本阶段。

**本阶段的数值口径（用户规定）**：

- 基础武器时，单位数值等于一代对应兵种的 **1 级**数值；升级成任一高级武器后，等于对应兵种的 **3 级**数值。
- **熟练度与头衔沿用一代**（用户 2026-11-06 追加）：
  - 二章单位靠经验自动升级，经验门槛用对应兵种 XML 的 `Experience`；
  - 头衔：1 级无前缀，2 级 Hardened，3 级 Veteran，3 级且经验满为 Elite；
  - 基础武器只能升到 2 级，1、2 级分别取对应兵种 1、2 级的数值；
  - **2 级经验练满后才能换高级武器**（用户已确认），对应一代“基础兵到 Elite 才能进阶”。换上后直接升到 3 级，经验清零；
  - 直接招募的高级武器单位从 3 级起步；
  - 两把高级武器之间可以随时互换，等级与经验保留。
- 对应关系：镇戍卫 ↔ 一代骑士（knight），火铳卫 ↔ 一代弩手（crossbowman）。
- 火铳系列的射程等于一代狙击手：`search_radius 70 × 4.9 = 343`。
- 招募价用对应兵种类的静态 `unit_cost`：骑士 320、弩手 340。基础换高级的换装费 = 对应兵种 XML `money_upgrade` × 2：镇戍卫 600、火铳卫 300。A、B 两把高级武器之间互换，收 `money_upgrade` × 1。这些都是起测值。
- 第二章战斗里**角色和战斗音效全部静音**，音乐照常。

公共规则（禁令、headless、日志、导入锁、不跑全量测试、不提交）同 `docs/ch2-m0-spec.md` 第 0 节。美术资源的格式见 `docs/ch2-art-pipeline.md`。

### D1.1 种类与工厂

- 在 `ch2_kinds.gd` 追加常量：`CH2_WARDEN = 100`、`CH2_MUSKETEER = 101`、`CH2_DARTH_LANCER = 150`，名字映射为 `"CH2_WARDEN"` 等。
- 新建 `game/ch2/units/ch2_unit_factory.gd`，提供 `new_unit(kind) -> LivingObject`。
- 在 `GameUniverse._new_unit(kind)` 开头加一行：`kind >= 100` 时交给工厂。一代的 kind 都小于 100，不受影响。
- 新单位也要像一代单位一样走 SimpleCache 对象池和 `init_resources` 预热。Main 的预热队列里怎么加由 D2 负责，D1 提供静态方法 `init_resources()`。

### D1.2 纸娃娃运行时

**`Ch2BmpFrames extends BmpFrames`**，由 `body.json` 加上一份帧停留表构造：

- 每个动作对应一个 Ch2BmpFrames：
  - 先把 8 张原帧按停留表展开成逻辑帧；
  - `frame_commands` 在 DONE 帧对应的第一个逻辑帧写 2（DONE），循环动作的末帧写 0，非循环动作的末帧写 STOP（1），写法与一代的规则一致。
- **停留表起测值**（单位：逻辑帧）：

  | 动作 | 停留 | 合计 |
  | --- | --- | --- |
  | idle | 每帧 3 | 24 |
  | walk | 每帧 3 | 24 |
  | attack | `[3,3,3,2,4,3,3,3]` | 24，约等于一代骑士攻击动画 24 帧 |
  | 火铳 attack（射击） | `[2,2,3,3,4,3,3,2]` | 22 |
  | reload | 每帧 4 | 32 |
  | skill / brace | `[3,3,3,3,6,3,3,3]` | |
  | death | `[3,3,3,3,3,3,4,30]` | 末帧长停 |
  | 重骑 charge | 每帧 2 | 循环 |

- **`apply_frame(sprite, i)`**：
  - 不给 sprite 本身设纹理，而是在 sprite 下维护 3 个子节点：`ch2_body`、`ch2_weapon`、`ch2_offhand`（都是 Sprite2D，缩放 0.5）；
  - 一代的朝向翻转靠 `sprite.scale.x = ±1`，子节点随之一起翻，自然生效；
  - 武器纹理从 `sprite.get_meta("ch2_weapon")` 取（由单位在换武器时写入）。按该帧的 rod：武器图的 butt 对准 rod.butt，旋转到 rod 的角度，长度为武器逻辑长度 × 2，以 butt 为枢轴；
  - 盾按 disc 的中心与角度贴；rod 或 disc 为 null 的帧隐藏对应子节点；
  - 每帧把当前 rod 的 tip，也就是火铳的枪口位置，换算到单位本地坐标，写进 `sprite.set_meta("ch2_muzzle", Vector2)`，供弹道使用。
- **影子**：单位脚下画一个半透明深色椭圆，参照一代单位帧里自带的影子：大小约 22×7 逻辑像素，重骑约 34×9，alpha 约 0.35。放在单位节点下、sprite 之前。
- **命中热区 sens**：一代用 `sens_class` 符号。二章单位改用一个按身体尺寸生成的透明矩形纹理，宽约 18、高约 36 逻辑像素，重骑约 34×40，保证点击选中和 `hit_test_unit` 正常。实现时先读 `LivingObject` 里 sens 与 `_sens_alpha_cache` 的写法，选侵入最小的方式。

### D1.3 单位类

**`Ch2Warden extends MeleeFighter`**、**`Ch2Musketeer extends RangedFighter`**：

- 持有 `weapon: Ch2WeaponDef`。数值按 D1.4 的表，在 `update_stats` 里设置，不读一代 XML 节点。
- **`set_weapon(id)`**：

### D1.5 火铳弹道与射击

- **出手时机**：射击动画的 DONE 帧调用 `throw_ranged`，沿用一代的时机。Ch2Musketeer 重写 `throw_ranged`：
  - **命中判定**：沿用一代 `RangedFighter.throw_ranged` 的 RWRandom 调用顺序。先判断 `rand() <= shoot_accuracy`，未命中时再先后取 x、y 偏移各一次；
  - **出射点**：取 `sprite` meta `ch2_muzzle`，换算到世界坐标；
  - **弹丸** `Ch2Bullet`：按逻辑帧推进，不用 RWTween。由 GameUniverse 的 `update_effects` 每帧驱动，可挂成 VisualsTemplate 子类，或另建一个列表、在 `update_effects` 末尾调用。暂停和 2 倍速都要正确：2 倍速时每逻辑帧更新两次，暂停时停住。
    - 速度 22 px/逻辑帧，直线飞行，用 `ball_tracer` 精灵；
    - 命中帧调用 `missile_hit_handler(target)` 结算，伤害公式沿用 RangedFighter 的护甲减伤；
    - 未命中时飞到偏移点，播 `ball_impact` 扬尘，不结算伤害。
  - **开火瞬间**：在枪口播 `muzzle_flash`（加色，锚点在左侧中点，旋转到枪口朝向）；同一位置生成 2 个 `powder_smoke`，随机向上漂移 8–14 px 后淡出，漂移量用 `randf`（纯装饰，不消耗 RWRandom）。
  - 弹丸命中目标时，在目标身上播 `ball_impact` 的前 4 帧。
- **装填**：
  - **制式火铳**：每发之后播放 reload 动画。远程攻速 85 帧，等于“射击动画 + 装填”的完整周期；装填中移动会暂停装填进度，停下后继续。
  - **五雷神机**：弹匣 5 发，每发间隔 9 帧，可以连续打同一目标，目标死亡则换下一个；打空后长装填 150 帧，期间播放 reload 动画。移动同样暂停装填。弹匣剩余数写进单位字段，供 D2 的单位面板显示。
  - **重管火铳**：单发；装填播 reload 动画，周期 105 帧。
- **特殊弹**（技能）：替代下一发普通射击，消耗同一个弹位或同一次射击动作，不额外多给一发。
  - 冷却在“装上特殊弹”的那一刻开始计算；
  - 装填期间不能越过装填开火；
  - 一次只预备一种特殊弹。

### D1.6 达思重骑冲锋与陌刀拒马

**`Ch2DarthLancer` 状态机**（在 `before_updating_active_unit` 或 `update` 中，按逻辑帧推进）：

1. **FORM**：到达关卡指定的整队点后原地停 60 帧，播 form 动画；地面显示一个预警箭头，指向冲锋方向，用 `hoof_dust` 或简单的绘制。
2. **COMMIT**：确定冲锋目标点：取方向锥 ±25° 内、最近的玩家单位团块中心；没有就取关卡给的 `charge_target` 锚点，比如港门。确定后锁定直线，冲锋全程不转向。
3. **CHARGE**：
   - 沿直线每帧前进 4.0 px，播 charge 动画，每 4 帧在马后撒一次 `hoof_dust`。
   - 碰撞判定：用当帧 `lance_tip` 的世界坐标，加上以马身为中心、宽 14 px 的走廊。
   - 撞到的第一个**非拒马**玩家单位：吃撞击伤害和 30 帧眩晕，沿冲锋方向的垂直方向被推开 20 px，路径上的障碍掩码要尊重，不能推进墙里。重骑减速到 0，进入 IMPACT。
   - 走廊里撞到**正在支势的陌刀**（见下）：触发拒马。
   - 到达终点，或撞上障碍掩码：直接进入 IMPACT。
4. **IMPACT**：停 45 帧，用 form 动画的第 1 帧代替恢复姿势；之后进入 MELEE。
5. **MELEE**：交还一代 MeleeFighter 的索敌与攻击逻辑。每名重骑**只冲锋一次**（“近战后不重复结算冲锋”）。

**拒马斩 Horsebreaker**（陌刀技能 1，自动施放）：

- **支势条件**：陌刀单位不在移动、技能冷却就绪，且有重骑处于 COMMIT 或 CHARGE 状态、距离 220 px 以内、冲锋直线会经过它 40 px 以内。满足时自动转向迎骑，播 brace 动画并停在第 4 帧保持支势，最多 90 帧。玩家下达移动命令会取消支势。
- **生效条件**：重骑的走廊接触到支势中的陌刀，并且重骑冲锋方向与陌刀朝向的夹角大于 120°，也就是正面迎上；侧后方来的不成立，此时按普通撞击处理。
- **效果**：
  - 冲锋立即取消：没有撞击伤害，不推开陌刀，陌刀不被眩晕；
  - 重骑受到拒马伤害：基础 = 陌刀近战伤害 × 6，按重骑护甲减伤（考虑陌刀破甲），再眩晕 60 帧；
  - 在接触点播 `brace_clash`，陌刀播 brace 动画第 5 帧及之后。
- **冷却与边界**：冷却 12 秒（360 帧）。一次支势只处理一名重骑；若两名并排冲来，另一名按普通撞击处理，这正是“宽阵面需要多名陌刀”。

### D1.8 静音

- `Sounds` 加静态开关 `ch2_sfx_muted`。为真时 `play()` 直接返回，`play_music` 不受影响。
- LevelCh2 在 `loading_completed_handler` 里置真，`clear_data` 时置假。
- `GameUniverse.init` 在 `chapter == 1` 时强制置假，属于 D1 在 game_universe 里的一行钩子。

### 第 11 关 Siege at Stone Wharf（火铳主场）

- **几何**：按底图描绘障碍：
  - 西侧、西南的河面；
  - 北侧仓房；
  - 西北升降台平台的木结构（台面本身可站立，但起重架算障碍）；
  - 南侧补给棚；
  - 东侧军械院的墙；
  - 坡道两侧的石栏。
  
  中央石板卸货场必须完全开阔。
- **路线**：
  - 敌人从东侧外堤进入，北、南各一条入口，沿堤走下坡道进入卸货场；
  - 另有一条南侧小路从画面下边进入；
  - 友军入场路线是从西侧码头上岸，回到 recruit 锚点（码头船边）。
- **开局**：
  - 玩家：6 名制式火铳卫、2 名五雷、2 名重管（共 10 名火铳），4 名刀盾镇戍卫，2 名一代治疗者（FR_HEALER）；
  - 金钱约 1200，用于补员和换装；
  - 许衡作为对白说话人，不必是单独的单位。
- **目标**：
  - 守住升降台（protect，HP 600）；
  - 军械队分两批从东侧军械院撤到西侧码头（evac，每批 5 人，每批至少 4 人到达）；
  - 文字用 `data/ch2/text/levels.json` 第 11 关的 objectives id，没有完全匹配的就选最接近的，并报告。
- **阶段**（起测值，总敌量约 150，同屏不超过 40）：
  1. **整队**：开场就开招募窗口，45 秒，玩家可以布阵；播开场对白。
  2. **第一波**：两条堤路共来 30 名僵尸和灰僵尸。
  3. **军械队第一批出发**，同时来第二波：40 只，包括僵尸、骷髅、装甲骷髅，从堤路和南路两个方向来。
  4. **招募窗口**。
  5. **军械队第二批出发**，同时来第三波尸潮：60 名僵尸、瘟疫僵尸和灰僵尸，另有 4 名达思骑士压阵，坡道上方有 6 名骷髅弓手。
  6. **收尾**：停止出兵，清理残敌。
- **胜负**：
  - 胜：军械队两批都达到配额、升降台存活、阶段全部完成、场上没有敌人；
  - 负：升降台被毁、任一批军械队人数不足、或玩家失去全部战斗力。
- **对白**：使用 `dialogue.json` 里第 11 关的事件，放在整队期和各批出发之前。

  - 慢尸走两条南路；
  - 友军入场是从港门出来，回到 recruit 锚点。

- **阶段**（起测值，重骑共约 18 名）：
  1. **示范**：1 名重骑从西路整队、冲锋，给足观摩拒马的时间。
  2. **第二轮**：2 名重骑从同一宽路先后冲来，间隔 3 秒。
  3. **招募窗口**。

  6. **收尾**：停止出兵，清理残敌。
- **胜负**：
  - 胜：港门存活、阶段全部完成、场上没有敌人；
  - 负：港门被毁，或玩家失去全部战斗力。
